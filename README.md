# Keshi Studio · 芥子

**芥子纳须弥，一念转流光**  
*A universe in a seed. Shaping light without a trace.*

---

本地桌面视频工具：自然语言描述需求 → 动态表单 → 内置 ffmpeg 转码（转格式等）。  
Electron + React + Vite，Windows 安装包双击即用，托盘常驻。

## 快速开始

```bash
npm install
npm run dist
```

安装包输出在 `release/`。开发调试：`npm run dev` + `npm run electron`。
