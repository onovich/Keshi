# Keshi

[English](README.md)

Electron 桌面视频工具，用自然语言生成参数表单并调用内置 ffmpeg 转码。

![Keshi 封面](docs/cover.png)

## 项目包含什么

- 自然语言描述任务。
- 动态参数表单。
- 桌面应用。

## 快速开始

安装依赖并启动本地版本：

```bash
npm install
npm run dev
```

仓库还提供 `npm run build`、`npm run lint`。

## 仓库结构

- `src/` — 应用与库的源代码。
- `public/` — 公开静态资源。
- `index.html` — Web 入口。
- `package.json` — 包脚本与依赖。
